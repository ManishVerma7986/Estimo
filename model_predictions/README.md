# Model Predictions Directory

This directory stores exact local ML prediction results and the combined cost-estimation output generated by the offline model pipeline, baseline cost calculators, Monte Carlo simulations, and historical project analogies.

### Exact Local Model Output
- `local_model_prediction_{session_id}_{timestamp}.json`: The unmodified result object returned by the local ML inference function.
- `latest_local_model_prediction.json`: The most recent local ML result. Successful predictions include the resolved model file path so the artifact shows which on-disk model was loaded.

### Combined Pipeline Output
- `model_prediction_{session_id}_{timestamp}.json`: Complete software, hardware, and unified estimate record.
- `latest_model_prediction.json`: Most recently generated combined estimate.

The combined files contain:
- `software_development_estimate`:
  - `baseline_estimate`: Transparent itemised labor breakdown, software BOM licenses, direct materials, direct labor, overheads, contingency, and taxes.
  - `ml_prediction`: Offline ML model inference (e.g., XGBoost on Desharnais dataset), model target, version ID, predicted effort person-hours, feature schema, and residual-based confidence intervals.
  - `monte_carlo_simulation`: 2,000 empirical trials with distribution percentiles (P10, P50, P90, Mean, Std Dev) and top cost-driving parameters.
  - `analogies`: Top k-nearest historical project matches retrieved using normalized distance metrics from the registered historical dataset.
- `unified_prediction_summary`: Combined project cost synthesis (Optimistic, Likely, Pessimistic totals, hardware vs. software breakdown, timeline months, and executive summary).

Nemotron's separate narrative response is saved under `../nemotron_responses/`; it does not replace or modify the numeric local estimate.
